# 安装说明（先看这一页）

## 一、装哪个文件

| 文件 | 说明 |
|------|------|
| **生态环境法典检索-v1.0.apk** | **装这个**，正常使用 |
| 生态环境法典检索-v1.0-debug.apk | 不用管，开发者调试用的 |
| 使用说明书.html / .md | 使用说明书，两个内容一样；手机上推荐点开 .html 那个，排版更好读 |

## 二、装到手机上（三步）

**第一步**：把 APK 传到手机
用微信"文件传输助手"发给自己，或者用数据线拷贝，都可以。

**第二步**：在手机上点一下这个文件
手机会问是否允许安装，选**允许**。
如果提示"未知来源应用"，进入弹出的设置里，把对应来源（微信、文件管理器等）设为允许安装，然后再点一次。

**第三步**：装好后，桌面出现图标
**绿色方块 + 白色天平**，名字叫「生态环境法典检索」，点开就能用。

第一次打开需要一两秒准备，之后就很快了。

## 三、手机上够用吗

- 安卓 7.0 以上基本都可以
- 安装包约 8MB，占用空间很小
- **不用联网**：装上之后开飞行模式也能正常查、正常看、正常听朗读
- 不用注册，不用登录，没有广告
- 说明：安装时系统可能显示"需要网络权限"，这是打包框架的默认声明；**这个工具实际不会联网**，你可以开飞行模式验证

## 四、装上之后先试这三件事

1. 在搜索框里打「**噪音**」，看能不能搜出关于噪声的条文
2. 随便点开一条，按一下 **🔊**，试试朗读有没有声音
3. 点右上角小喇叭旁边的图标，试试背景音

哪一步不对，就翻《使用说明书》第八节"常见问题"。

## 五、这个工具能做什么

- **查法典**：1242 条全文，用平常说的话就能搜到
- **看条文**：条文里提到的其他条款，点一下就跳过去
- **听条文**：可以朗读，开车、走路、眼睛累的时候用
- **存条文**：点 ☆ 收藏，写材料时一键复制规范引用
- **护眼**：三种配色（白底 / 护眼米黄 / 夜间深色），字号能放大
